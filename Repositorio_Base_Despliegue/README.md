# Repositorio Base de Despliegue

Estructura inicial para organizar archivos de despliegue y administración de servidores.

## Carpetas

- `cronjob/`: archivos para configuración de tareas programadas.
- `envs/`: archivos de configuración de entornos (desarrollo, prueba y producción).
- `nginx/`: configuración del servidor web y proxy inverso.
- `scripts/`: scripts utilizados en el despliegue.

## Nota

Las carpetas se entregan inicialmente vacías porque no se proporcionaron scripts ni archivos de configuración específicos.
Añade los archivos correspondientes según las instrucciones de la actividad.
